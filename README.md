# Council of AI (CSOAI Ltd · UK 16939677)

**Independent measurement body.** We measure AI systems against frozen, published banks, sign the result (Ed25519), and re-attest when a measurement changes. We do not certify, accredit, enforce, or sell a rank.

### Living board

Counts come from **[GET https://councilof.ai/api/gspc](https://councilof.ai/api/gspc)** — never a number typed into this page. Today that payload prints **`22 axis · 15 measured`**. Empty slots stay empty. A TIE is a TIE, never a win. Jail (containment) is measured; its separation is TIE.

If this README disagrees with the endpoint, the endpoint wins.

### Method

Deterministic gold labels. No model judges another model. Canonical methodology DOI [10.5281/zenodo.21991104](https://doi.org/10.5281/zenodo.21991104). Corrections are published, never silently edited.
